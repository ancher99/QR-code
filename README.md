# Проект по генерации и сканирования qr кода  на React (учебный проект)

## Описание проекта 
 Основная цель данного учебного проекта это создать веб-приложения для генерации, сканирования, и хранение созданного или отсканированного **qr**. 
 Проект создан с помощью **React + Vite** для практики использования **jsx** разметки. Данные храняться в **localstorage**.
