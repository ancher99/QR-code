# Проект по генерации и сканирования QR-кода  на React (учебный проект)

## Описание проекта 
Целью данного учебного проекта было создание комплексного веб-приложения для работы с QR-кодами: генерации новых кодов, их сканирования (чтения) и последующего хранения истории операций. Приложение разработано с использованием связки **React + Vite**, что позволило эффективно отработать навыки работы с **JSX-разметкой** и **компонентным** подходом. Для хранения данных о созданных и отсканированных QR-кодах используется **LocalStorage**.
